You are an autonomous coding agent. Your task is to build the **CountrySearch** web application from scratch.

## How to Use These Files

Read the following `.md` files **in order** before writing any code. Each file is a self-contained specification for one concern of the application. Use them as your source of truth.

| Order | File | Purpose |
|-------|------|---------|
| 1 | `README.md` | This file — start here |
| 2 | `PROJECT.md` | App overview, goals, constraints |
| 3 | `ARCHITECTURE.md` | Folder structure & module design |
| 4 | `MODELS.md` | Data models & class structures |
| 5 | `API.md` | External API contract & usage |
| 6 | `FEATURES.md` | All features and UI behaviour |
| 7 | `STYLING.md` | Visual design guidelines |
| 8 | `DONE.md` | Acceptance checklist — verify before finishing |

## Rules

- Read **all** files before writing a single line of code.
- Do not ask for clarification — every decision is specified across these files.
- If something is not specified, use your best judgment and keep it consistent with the rest of the spec.
- Write clean, well-commented code a student can learn from.
